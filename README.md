# Последний рубеж

Браузерная tower defense на Canvas 2D. Никаких библиотек, внешних ассетов, сетевых запросов, сборки или установки пакетов. Карта, башни, враги, частицы и интерфейсные значки рисуются кодом; звук синтезируется Web Audio API. Используются только системные шрифты.

## Запуск

Откройте **index.html** в современном браузере. Сохраняйте структуру проекта: рядом с `index.html` должны находиться папки `css/` и `js/` с игровыми файлами.

Либо выполните в этой папке одну команду при установленном Node.js:

```sh
node scripts/server.cjs
```

Откройте **http://127.0.0.1:8080**. Сервер использует только встроенные модули Node.js, слушает локальный адрес; `npm install` не нужен. Остановка — Ctrl+C. Порт можно изменить переменной окружения `PORT`.

## Как играть

У базы 30 жизней, в начале — 700 кредитов. Выберите модуль справа, затем нажмите на свободный участок вне дороги. Зелёный контур разрешает строительство, красный показывает препятствие или нехватку денег. Повторные нажатия размещают несколько башен выбранного типа. Нажатие на существующую башню открывает улучшения и продажу.

У каждой башни **базовый уровень I и три платных улучшения: II, III, IV**. Улучшения повышают урон, дальность, темп стрельбы, а у площадного оружия — также радиус взрыва. Продажа возвращает 70% всех вложенных кредитов с округлением вниз. Цены покупки и улучшений видны до нажатия.

| Модуль | Цена | Механика |
| --- | ---: | --- |
| Пулемёт | 90 | Частый прицельный огонь по одной цели |
| Мортира | 170 | Летящий снаряд со взрывом по площади |
| Крио | 120 | Площадной импульс, урон и замедление; босс сопротивляется заморозке |
| Лазер | 240 | Сквозной луч по линии, игнорирует броню, тройной урон боссу |
| Ракеты | 310 | Самонаводящийся боеприпас, дальняя стрельба и большой взрыв |
| Токсин | 190 | Область заражения; яд наносит урон 4 секунды и игнорирует броню |

Яд не складывается бесконечно: применяется сильнейший эффект, повторный удар обновляет длительность. Крио и площадное оружие хорошо работают вместе. Обычные башни прежде всего атакуют врага, прошедшего дальше остальных.

Нажмите «Начать волну», когда готовы. Следующая волна запускается вручную после уничтожения предыдущей. Строить, улучшать и продавать можно в бою и на паузе. Деньги выдаются за убийства и завершение волны. Разведчики, бегуны, броневики и элита отличаются скоростью, здоровьем и наградой.

Всего 10 волн: 24, 65, 140, 280, 520, 900, 1500, 2600, 3200 и 3600 обычных врагов. На последних волнах враги значительно выносливее, и одновременно в секторе могут находиться более 2000 целей. На десятой волне появляется **Титан** с отдельной полосой здоровья. Для победы нужно уничтожить и босса, и весь его эскорт. Пропущенный обычный враг отнимает одну жизнь; дошедший Титан сразу уничтожает базу. После победы и поражения можно начать новую операцию.

Звук включается после первого действия из-за правил браузеров. Его можно отключить кнопкой ♫. При скрытии вкладки игра автоматически ставится на паузу; возвращение не возобновляет бой без вашего нажатия.

| Управление | Действие |
| --- | --- |
| 1–6 | Выбрать тип башни |
| Левая кнопка / касание | Построить или выбрать башню |
| Escape / правая кнопка на карте | Отменить выбор |
| U / X | Улучшить / продать выбранную башню |
| Пробел | Пауза / продолжить |
| N | Начать следующую волну |
| F | Переключить ×1 → ×2 → ×4 |
| M / H | Звук / руководство |

## Проверки

Движок проверяется встроенным тестовым раннером Node.js:

```sh
node --test tests/engine.test.cjs
```

Полное воспроизводимое прохождение всех 10 волн без добавления денег или изменения здоровья врагов:

```sh
node tests/playthrough.cjs
```

Этот сценарий пользуется обычными покупками и улучшениями за заработанные кредиты. Дополнительно проверяет, что на волнах 9 и 10 одновременно остаются живы более 2000 врагов даже против развитой обороны.

Для проверки настоящего браузера запустите сервер, откройте **http://127.0.0.1:8080/tests/browser.html** и нажмите «Запустить проверки». Держите вкладку активной около 50 секунд. Проверяются клики по карте и интерфейсу, запрет строительства без денег и на дороге, все улучшения, продажа, горячие клавиши, пауза, скорости, Web Audio, руководство, перезапуск, босс и оба финальных экрана. Результат и замеры появятся под игрой. В нагрузочном режиме врагам восстанавливается здоровье и замыкается маршрут, чтобы во время всего замера оставалось ровно 3000 движущихся целей; 48 башен уровня IV продолжают стрелять, замедлять и отравлять их. Дополнительный предельный сценарий использует 3600 врагов и 96 башен на ×4. Эти правила действуют только на тестовой странице. Для запуска только предельного сценария используйте **http://127.0.0.1:8080/tests/browser.html?maximum**.

Проверено 30 октября 2026: 19 тестов движка, полное прохождение и браузерные проверки. Результаты нагрузочного теста на доступной машине, Windows x64, Chromium 156:

| Скорость | Врагов | Башен IV | Средний FPS | Минимум за 1 секунду | p99 кадра |
| --- | ---: | ---: | ---: | ---: | ---: |
| ×1 | 3000 | 48 | 144 | 144 | 7,1 мс |
| ×2 | 3000 | 48 | 144 | 144 | 7,1 мс |
| ×4 | 3000 | 48 | 144 | 144 | 7,1 мс |
| ×4, предел | 3600 | 96 | 121,9 | 118 | 14 мс |

Каждый замер: 1,8 секунды прогрева + 8 секунд измерения реальных `requestAnimationFrame`, исходный размер окна 1280×720. FPS зависит от оборудования, браузера и нагрузки системы; абсолютная гарантия для любого устройства невозможна. Встроенный тест отмечает ошибку, если минимум за секундный интервал ниже 30 FPS. Прямой `file://` запуск не проверялся автоматизацией: её браузер разрешает только HTTP/HTTPS. Запуск одной командой и игровая работа проверены через локальный HTTP.

Исходные браузерные отчёты: `tests/reports/browser-report.json` (37 успешных проверок), `tests/reports/maximum-report.json` (31 успешная проверка, включая предельную нагрузку). Снимки фактического боя: `tests/screenshots/qa-swarm.jpg`, `tests/screenshots/qa-maximum.jpg`. Изображения используются только как доказательство проверки и не загружаются игрой.

## Производительность и устройство

- Данные врагов хранятся в типизированных массивах; до 16 384 слотов переиспользуются после смерти.
- Путь рассчитан заранее, координаты берутся из таблицы с интерполяцией.
- Пространственная сетка 64×64 ограничивает поиск целей и обработку взрывов соседними ячейками.
- Статическая карта закэширована в отдельном canvas. Враги и индикаторы эффектов рисуются пакетами, без DOM-элемента, тени или поворота контекста на каждого врага.
- Симуляция использует фиксированный шаг 1/60 с и интерполяцию при отрисовке; ускорение увеличивает число шагов, а не скорость полёта снарядов относительно врагов.
- Частицы ограничены 560 элементами, снаряды — 256, события кадра — 256. При низком FPS уменьшается количество декоративных частиц, игровые правила сохраняются.
- На карте максимум 96 башен; плотность canvas ограничена 1,6×. Звук выстрелов ограничен по частоте.

```text

├── index.html
├── package.json
├── README.md
├── js/
│   ├── engine.js             # независимая симуляция
│   └── game.js               # отрисовка, звук и управление

│   └── style.css             # адаптивный интерфейс
├── scripts/

    ├── browser.html          # браузерная проверка

    ├── css/browser.css       # стили страницы проверок
    ├── reports/              # JSON-отчёты
    └── screenshots/          # снимки проверок
```
